解説

      
    
        
  • ボタンを押すと、定義済みのクエリを API 経由で実行し、実行された SQL と結果を表示します。
    • 
        
  • Users count: COUNT(*) の結果は1行なので、get() で取得します。
    • 
        
  • Feeds JOIN users: feeds と users を JOIN し、投稿者名つきの feeds を取得します（SQL は Feeds ページと同じ）。
    • 
        
  • Find by email: WHERE email = ? のプレースホルダに、入力した値を渡して検索します。
    • 
        
  • 任意の SQL を実行したいときは、ターミナルで node db_query.js "SELECT * FROM users LIMIT 3" を使います。
    • 
      

      
// models/User.js: 件数 (1行だけ返すので get())
export const count = () => {
    const sql = "SELECT COUNT(*) AS count FROM users;";
    const statement = db.prepare(sql);
    const row = statement.get();
    return { count: row.count, sql };
};

// models/User.js: メールで検索 (? に値を渡す)
export const findByEmail = (email) => {
    const sql = "SELECT id, name, email, created_at FROM users WHERE email = ?;";
    const statement = db.prepare(sql);
    const users = statement.all(email);
    return { users, sql: format(sql, [email]) };
};
