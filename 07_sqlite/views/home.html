API 一覧

各ページから呼び出している API です。データ取得は GET、追加・更新・削除は POST を使います。

Endpoint機能SQL解説
GET/api/db/status 接続確認 SELECT sqlite_version() Home の Connected 表示
GET/api/db/tables テーブル一覧 sqlite_master / PRAGMA table_info / COUNT(*) テーブル名・件数・カラムを返す
POST/api/db/create テーブル作成 schema.sql を実行 (CREATE TABLE) なければ作成
POST/api/db/drop テーブル削除 DROP TABLE feeds → users の順に削除
POST/api/db/seed テストデータ投入 INSERT (BEGIN … COMMIT) faker で users 10件・feeds 30件
POST/api/db/truncate 全データ削除 DELETE AUTOINCREMENT もリセット
GET/api/users ユーザー一覧 SELECT … LIMIT ? ?limit= で件数指定
GET/api/users/count ユーザー数 SELECT COUNT(*) SQL Client 用
GET/api/users/by-email メールで検索 SELECT … WHERE email = ? ?email= を ? で安全に渡す
GET/api/feeds 投稿一覧 SELECT … JOIN users 新しい順に取得
GET/api/feeds/join JOIN の結果 SELECT … JOIN users SQL Client 用
POST/api/feeds 投稿 INSERT user_id・content を受け取る
POST/api/feeds/transaction トランザクション BEGIN → INSERT×2 → COMMIT 失敗時は ROLLBACK
POST/api/feeds/injection SQL インジェクション (デモ) exec() で文字列連結 ⚠️ 危険な例
POST/api/feeds/:id/update 投稿の更新 UPDATE … WHERE id = ? content を更新
POST/api/feeds/:id/destroy 投稿の削除 DELETE … WHERE id = ? id で 1 件削除

node:sqlite の基本

項目コード解説
Connected の表示 GET/api/db/status SELECT sqlite_version() 上の Connected は、このクエリを実行できたときに表示されます。接続できないときは Not connected とエラーが表示されます。
接続 new DatabaseSync(ファイルパス) DB は 1 つのファイル（database/app.db）で、DB サーバーは不要です。
SQL の準備と実行 prepare(sql) SQL を準備し、all()（全件）・get()（1 件）・run()（追加・更新・削除）で実行します。
結果が不要な SQL db.exec(sql) CREATE TABLE・BEGIN・COMMIT など、結果が不要な SQL の実行に使います。
値の渡し方 ? 値は ? のプレースホルダで渡します。処理は同期なので await は不要です。
画面で確認 Endpoint / SQL / Message 各ページの上部で、呼び出した API と実行された SQL を確認できます。 
import { DatabaseSync } from 'node:sqlite';

const db = new DatabaseSync('database/app.db');       // 接続 (ファイルがなければ作成)
db.exec('PRAGMA foreign_keys = ON;');                 // 結果が不要な SQL は exec()

// SQL を準備して、all() / get() / run() で実行する
const selectAll = db.prepare('SELECT * FROM users');
const users = selectAll.all();                  // 全件 (配列)

const selectOne = db.prepare('SELECT * FROM users WHERE id = ?');
const user = selectOne.get(1);                  // 1件 (なければ undefined)

const insertUser = db.prepare('INSERT INTO users (name, email) VALUES (?, ?)');
const result = insertUser.run('Taro', 'taro@test.com');   // { changes, lastInsertRowid }

db.close();
