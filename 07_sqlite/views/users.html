解説

      
    
        
  • ページを開くと GET/api/users を fetch し、返ってきた JSON をテーブルに描画します。
    • 
        
  • ルート → コントローラー → モデルの順に呼ばれ、モデルが prepare() で SQL を準備し、all(limit) で全件を取得します。
    • 
        
  • LIMIT ? の ? はプレースホルダです。値は SQL に直接埋め込まず、all(limit) の引数で渡します。
    • 
        
  • 上の Endpoint / SQL / Message は、実際に呼び出した API と実行された SQL です。
    • 
        
  • 日時は CURRENT_TIMESTAMP で UTC のまま保存され、画面で日本時間に変換して表示しています。
    • 
      

      
// 画面 (views/users.html)
const result = await api('/api/users');

// routes/routes.js
router.get('/api/users', Api.userList);

// controllers/ApiController.js
export const userList = (req, res) => {
    const result = User.fetchAll(Number(req.query.limit) || 20);
    res.json({ users: result.users, sql: result.sql, message: 'Listed', errors: [] });
};

// models/User.js
export const fetchAll = (limit = 20) => {
    const sql = "SELECT id, name, email, created_at FROM users ORDER BY id LIMIT ?;";
    const statement = db.prepare(sql);
    const users = statement.all(limit);
    return { users, sql: format(sql, [limit]) };
};
