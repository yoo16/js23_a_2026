解説

      
    
        
  • テーブル作成: POST/api/db/create。migrate() が schema.sql を読み込み、exec() で実行します。IF NOT EXISTS なので、何度押してもエラーになりません。
    • 
        
  • テストデータ投入: POST/api/db/seed。faker で作ったダミーデータを、BEGIN ～ COMMIT のトランザクションでまとめて INSERT します。email は UNIQUE なので、番号は既存の件数から続けて採番しています。
    • 
        
  • 全データ削除: POST/api/db/truncate。DELETE でデータだけを消し、sqlite_sequence も消して ID の採番を 1 に戻します。テーブルは残ります。
    • 
        
  • テーブル削除: POST/api/db/drop。DROP TABLE でテーブルごと消します。feeds は users を参照しているため、feeds を先に削除します。
    • 
        
  • Tables: GET/api/db/tables。sqlite_master からテーブル名を取得し、PRAGMA table_info() でカラム、COUNT(*) で件数を調べています。
    • 
      

      
// models/Db.js: テーブル作成 (schema.sql を実行)
export const create = () => {
    const schema = path.resolve('database/schema.sql');
    const text = fs.readFileSync(schema, 'utf-8');
    const sql = text.trim();
    migrate();   // lib/db.js: db.exec(schema.sql の中身)
    return { errors: [], sql };
};

// models/Db.js: テーブル一覧
export const tables = () => {
    const sql = "SELECT name FROM sqlite_master WHERE type = 'table' AND name NOT LIKE 'sqlite_%' ORDER BY name";
    const statement = db.prepare(sql);
    const rows = statement.all();
    // 各テーブルについて、PRAGMA table_info() でカラム、COUNT(*) で件数を取得
    return { tables: rows, errors: [] };
};

// models/Db.js: 全データ削除 (SQLite に TRUNCATE はない)
export const truncate = () => {
    const sql = "DELETE FROM feeds;
DELETE FROM users;
DELETE FROM sqlite_sequence WHERE name IN ('feeds', 'users');";
    db.exec(sql);
    return { errors: [], sql };
};
